# Day 8 – Linux FASTA Quality Control

## Objective

Practice Linux commands commonly used in bioinformatics for sequence file management and quality control.

## Tasks Completed

* Created FASTA files and directory structure
* Identified empty FASTA files using `find`
* Detected ambiguous nucleotides (`N`) using `grep`
* Generated a quality-control summary report
* Moved corrupted files into a quarantine directory
* Counted FASTA files in the project

## Skills Practiced

Linux • FASTA files • grep • find • file management • quality control

## Outcome

Successfully simulated a basic bioinformatics sequence-cleaning workflow using Linux command-line tools.
